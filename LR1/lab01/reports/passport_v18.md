## 1. Цель и критерий

Проверить воспроизводимость учебного генератора текстур. Оценить, превышает ли эффект
фактора «линейная интерполяция вместо сглаженной» разброс между seed для контекста
«мраморный узор (обложка)».

- Критерий (записан в журнале до запуска, 2026-09-24 13:50:58 UTC): эффект существенен, если |Δ| > 2·s_base при n = 5.
- Гипотеза H: ни одна из четырёх метрик порог не превысит; наиболее вероятный кандидат на обнаружение — снижение контраста.

### Вывод

По заранее заданному критерию влияние линейной интерполяции не обнаружено при n = 5
ни по одной метрике. Гипотеза H не опровергнута.

Дополнительный анализ после основного вывода (не заменяет критерий): парные разности по
одинаковым seed отрицательны для контраста, граничной энергии и энтропии на каждом из
5 seed и на каждом из 20 seed. Это указывает на систематическое, но малое относительно
разброса между seed снижение. Подробнее — в отчёте, раздел 7.

## 8. Ограничения

- n = 5: оценка s сама неточна.
- Критерий |Δ| > 2·s учебный. Он сравнивает Δ с разбросом отдельных значений, а не с ошибкой среднего, поэтому его чувствительность не растёт с n.
- Одна модель-заменитель, один контекст, один базовый seed.
- Метрики описывают статистику яркости, а не эстетику обложки.
- Отсутствие обнаруженного эффекта не доказывает его отсутствия.
- Совпадение с демо проверено на двух средах (Windows/3.13.7/zlib 1.3.1 и macOS/3.14.2/zlib 1.2.12). Для других версий Python и zlib совпадение не гарантируется.
